## 🏗️ Project Architecture & Navigation

The site is built using a clean, serverless architecture optimized for high performance, mobile responsiveness, and global accessibility.

* **`/` (index.html):** Executive summary detailing my architectural philosophy, my First-Class Honours academic background, the GMT+2 global delivery advantage, and a dynamic technical tools wall.
* **`/projects:`** High-level gateway to structural data architecture deliverables and cloud deployments.
* **`/case-study-enterprise:`** Deep-dive analysis of a 200M+ row data warehouse rollout, including the mathematical reconstruction of 115M lost audit records using the Microsoft BI Stack (SSIS, SSAS, SSRS, SQL Server).
* **`/case-study-agriculture:`** Deep-dive analysis of a real-time, serverless cloud data portal built with Google Apps Script, BigQuery, and Looker Studio to eliminate manual agricultural tracking.
* **`/onboarding:`** A frictionless B2B engagement model outlining legal frameworks, Outside IR35 compliance for UK clients, asynchronous delivery models, and cross-border billing logistics.
* **`/contact:`** An AJAX-powered, secure inquiry form routing directly to my professional inbox via Formspree endpoints.

## 💻 Technical Stack (Front-End)

This portfolio eschews heavy JavaScript frameworks in favor of a lean, highly optimized vanilla stack, styled with a custom "Corporate Editorial" design system.

* **Markup:** HTML5 (Semantic, SEO-optimized structure)
* **Styling:** CSS3 (Custom CSS variables, Grid/Flexbox architecture, Mobile-first media queries)
* **Animation Engine:** [GSAP 3](https://greensock.com/gsap/) & ScrollTrigger for staggered, physics-based scroll reveals.
* **Scroll Physics:** [Lenis](https://lenis.studiofreight.com/) for interpolated, cubic-bezier smooth scrolling.
* **Form Handling:** [Formspree](https://formspree.io/) via asynchronous JavaScript (AJAX) fetches to prevent page redirects.
