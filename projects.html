Enterprise Data Architecture

Recovered 115M Records & Automated Multinational Enterprise Reporting

The Challenge: The client's legacy database overwrote historical states, destroying critical policy lifecycles. Furthermore, disparate systems across three countries caused severe reporting bottlenecks and conflicting KPIs.

The Solution: Architected a fully automated, end-to-end Microsoft BI pipeline establishing a singular, verifiable source of truth for over 200 million operational records.

Architectural Outcomes:
  • History Reconstruction: Parsed 115+ million raw audit logs to mathematically rebuild lost historical contract snapshots via specialized SQL environments.
  • Data Centralization: Consolidated 21.4 million contracts and 39.1 million transactions into a single automated data warehouse.
  • Semantic Modeling: Deployed SSAS Tabular Models to handle complex DAX measures, Pula FX conversions, and multi-tier arrears bucket migrations.
  • Data Governance: Enforced Row-Level Security (RLS) across Botswana, South Africa, and Zambia via an SSRS Native-Mode web portal.

Cloud Data Infrastructure

Real-Time Cloud Data Portal for Livestock Logistics

The Challenge: Field operations relied entirely on vulnerable analog paper records, causing multi-day reporting latency, data corruption, and a fundamental lack of executive visibility into farm logistics.

The Solution: Engineered a zero-maintenance, serverless cloud database application to digitize data collection directly from the field to the executive dashboard.

Architectural Outcomes:
  • Front-End Ingestion: Developed custom, mobile-responsive data entry interfaces utilizing Google Apps Script for field operators.
  • Backend Cloud Storage: Engineered automated pipelines to push sanitized, validated form data directly into structured, relational Google BigQuery tables.
  • Real-Time Visualization: Connected the BigQuery data warehouse directly to Looker Studio to deliver live operational metrics to stakeholders.
  • Business Impact: Achieved a 100% elimination of paper-based tracking, reducing data latency from 72+ hours to sub-60-second cloud synchronization.
