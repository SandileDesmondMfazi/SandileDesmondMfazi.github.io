Under The Hood: End-to-End Pipeline

[ ETL Architecture Diagram ]

1. Data Engineering (SSIS)

Simulated transactional data is extracted from legacy SQL tables via ODBC. SSIS packages perform in-stream data quality checks, handle missing values, and execute UPSERT commands into the staging warehouse.

[ Star Schema ERD ]

2. Dimensional Modeling

Designed following Kimball methodology. The central `Fact_Sales` table is surrounded by heavily conformed dimensions (`Dim_Date`, `Dim_Product`, `Dim_Store`), ensuring instantaneous slice-and-dice query performance.

// Dynamic YoY Revenue Growth VAR CurrentRevenue = [Total Revenue] VAR LastYearRevenue = CALCULATE( [Total Revenue], SAMEPERIODLASTYEAR('Dim_Date'[Date]) ) RETURN DIVIDE( CurrentRevenue - LastYearRevenue, LastYearRevenue, 0 )

3. Semantic Layer (DAX)

The SSAS Tabular model mathematically pre-calculates time-intelligence metrics and enforces Row-Level Security (RLS) so regional managers only view data strictly tied to their operational territory.
